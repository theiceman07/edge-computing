# Results and limitations (read this before citing any number)

## What is real and what is not
| Item | Origin |
|---|---|
| `data/raw/mpu6050_*` | **Real** recordings from this Pi, MPU6050 and motor. |
| `data/synthetic/*` (`sensor_mode=synthetic_calibrated`) | **Synthetic, NOT real.** Generated by `scripts/calibrate_synthetic.py`. |
| Normal synthetic runs | Parameters **fitted from 3 real motor-running recordings** (2026-11-05, sensor taped to motor). Fitted values and source files: `data/synthetic/calibration.json`. |
| Imbalance synthetic runs | **Assumed** fault model: fitted peak amplitudes x 2.0. Not fitted from real data (no usable real imbalance recording). |

Reason: the rig lost access to components (motor/battery issues, no heavier unbalance weight) and Pi access ends today.

## Real-data findings
- Only 3 real recordings have the motor spinning (2026-11-05). Their vibration std differs a lot between runs (0.15-0.76 g), consistent with a loosely mounted sensor, and the achieved rate was 43-49 Hz in two runs.
- The 11 normal runs and the 1 imbalance run from 2026-11-04 show almost no vibration (std 0.005-0.03 g): the motor was effectively not producing vibration at the sensor. The imbalance run differs from them only by a gravity-offset (tilt) change.
- Earlier model: flagged 68% of later normal runs (false alarms) and 100% of the 'imbalance' run. This reflects tilt/session differences, **not** imbalance detection.

## Synthetic-data result (software pipeline check only)
Isolation Forest trained on 6 synthetic normal runs, evaluated on 2 held-out synthetic normal and 4 synthetic imbalance runs:
| Label | Windows | Flagged |
|---|---|---|
| normal (false-alarm rate) | 120 | 55.0% |
| imbalance (detection rate) | 240 | 45.4% |

Detection is not meaningfully better than the false-alarm rate. The real normal signal is mostly broadband noise with run-to-run scale changes, so the assumed imbalance (stronger weak peaks) is not separable with these features. **No claim of fault-detection capability is supported by this project's data.**

## To make it real
Mount the sensor rigidly, record >=3 normal and >=3 imbalance runs at ~50 Hz with a clearly visible unbalance weight, retrain, evaluate on separate runs.
